{%- comment -%} Cookie consent bar. Ported from the sister sites' CookieConsent component (SecondStack, Antares) so behaviour stays the same across the portfolio: - Consent Mode v2 defaults to "denied" in _layouts/default.html, before GTM loads. Accept flips only analytics_storage to "granted"; the ad_* signals stay denied, since this site runs no ads. - The choice lives in localStorage (pp_cookie_consent), so a returning visitor is not asked again, and a stored choice is re-applied on every page. - Decline also deletes the GA cookies an earlier Accept left behind. - The footer's "Cookie settings" button ([data-cookie-settings]) reopens the bar at any time. It stays hidden until this script runs. - While the bar is up, the page gets the bar's height as bottom padding, so the bar never covers the footer links. - Included right after (fixed to the bottom by CSS), so keyboard and screen-reader users reach it first instead of after the whole page. - Rendered only when GTM is on (see default.html); styles in styles.css under "Cookie consent". The banner copy lives in the four assigns below. Change the words here only.
